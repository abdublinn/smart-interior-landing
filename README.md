# Smart Interior — лендинг для дизайнеров

Посадочная страница «Партнёрам-дизайнерам» для **Smart Interior** (премиум-мебель на заказ, Санкт-Петербург, kuhnismart.ru).

**Ось:** «Мы относимся к дизайнеру как ко второму клиенту — и защищаем вашу репутацию перед вашим заказчиком».

## Что внутри
- `index.html` — одностраничный лендинг (HTML/CSS, ванильный JS; адаптив, FAQ-аккордеон, плавающие мессенджеры).
- `kit/smart-interior-partner-kit.pdf` — партнёрский PDF-кит (лид-магнит под главный CTA).
- `kit/partner-kit-source.html` — HTML-исходник кита (для правок и перегенерации PDF).

## Структура лендинга
Hero → «ваша рекомендация = репутация» → зелёный коридор (что получает партнёр) → защита репутации → выгода клиенту → что отдаём/границы → производство → как начать (4 шага) → отзывы → FAQ → форма «получить пакет».

## Статус: черновик
В тексте есть пометки `[уточнить]` (выделены) — заполнить реальными данными Smart Interior до публикации:
- цифры производства, гарантийный срок, время ответа SLA, перечень брендов материалов;
- номер профлинии и контакт партнёрского менеджера;
- реквизиты компании;
- ссылки соцсетей (Telegram/VK) в шапке, футере и кнопках;
- **форма** подключается к CRM (Битрикс24); после отправки отдаётся PDF-кит (сейчас — fallback: прямое скачивание PDF).

## Источник
Лендинг собран по ТЗ (синтез мирового опыта работы с дизайнерами + партнёрского проекта МДЖ + лекций по сарафанному маркетингу). Подробности — во внутренних материалах проекта.
